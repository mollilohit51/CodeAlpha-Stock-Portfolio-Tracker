# CodeAlpha_StockPortfolioTracker

# Description
A simple Stock Portfolio Tracker developed using 
Python as part of CodeAlpha Python Programming Internship.

This application allows users to calculate the total value of their 
stocks investments by entering stock names and quantites. The program uses
predefined stock prices and generate a porfolio summary.

# Features
- Track multiple stock investments
- Calculate total portfolio value
- Predefined stock price database
- User-friendly console interface
- Save portfolio summary to a text file

# Technologies Used
- Python

# Concepts Used
- Dictionaries
- Loops
- Conditional Statements
- File Handling
- User Input and Output

# How to Run
1. Install Python
2. Open terminal or command prompt
3. Run the file:

python Stock_Portfolio_Tracker.py
